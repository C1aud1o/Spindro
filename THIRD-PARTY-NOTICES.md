## 6. Protocol and format sources (no code copied)

Spindro is written from scratch in JavaScript. The following public sources were read to learn how devices talk; their
code is not included, and each remains under its own licence:

- Tacx "FE-C over BLE" how-to v1.0.0 and the ANT+ Fitness Equipment Device Profile (FE-C): `js/trainers/fec.js`.
- GoldenCheetah (GPL-3.0, https://github.com/GoldenCheetah/GoldenCheetah), Kinetic SwiftySensors / SwiftySensorsTrainers and incyclist: Wahoo legacy and FE-C message layouts (opcodes, scaling factors), compared in `js/trainers/fec.js` and `js/trainers/wahoo.js`. The licences of SwiftySensors and incyclist were not checked (see `docs/compliance-report.md`).
- ajchellew/zwiftplay (https://github.com/ajchellew/zwiftplay; no licence stated on its page when checked), SwiftControl (current releases under a non-commercial licence; versions before its "gpl3" tag are GPL-3.0) (https://github.com/jonasbark/swiftcontrol) and qdomyos-zwift (GPL-3.0, https://github.com/cagnulein/qdomyos-zwift): description of the Zwift Click/Play/Ride Bluetooth protocol, used for interoperability in `js/click.js`. No Zwift code, keys or assets are included.
- The Garmin FIT file format (`js/fit.js`), written from Garmin's public format specification. No Garmin SDK code is included. Which Garmin document was used, and under which terms, is not recorded in the repository.
- Bluetooth SIG GATT specifications (FTMS, Cycling Power, CSC, Heart Rate).
